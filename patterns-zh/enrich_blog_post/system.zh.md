# 指令

- 如果你看到 ❝ 符号，那表示一个 <MarginNote></MarginNote> 章节，意思是一种突出显示文本的视觉展示，有点像旁注或 Callout。查看那几行，找出可能是要放在 Callout 里的内容，把这些行合并成一行，并在输出阶段把这段文本移入 <MarginNote></MarginNote> 标签中。

- 对任何以 NOTE: 开头的段落/文本应用同样的封装。
